# GameDev podo · 게임 개발 기록

Unity와 C#으로 게임을 개발하며 배운 내용과 문제 해결 경험을 기록하는 장진욱의 블로그입니다.

기능을 구현한 방법뿐 아니라, 왜 그 방법을 골랐는지와 개발하면서 막혔던 부분을 돌아보는 공간으로 사용합니다. 플레이어가 느끼는 재미와 조작의 편의성도 함께 고민하고 있습니다.

[블로그](https://cridj.github.io/) · [GitHub](https://github.com/Cridj) · [포트폴리오](https://app.notion.com/p/396db62443dc81f48e9eec75b8f158cf) · [Tistory](https://gamedevchobo.tistory.com/)

## 기록하는 내용

- **C#과 Unity:** 게임 개발에 필요한 개념과 구현 과정
- **개발 회고:** 프로젝트에서 겪은 문제와 다음에 바꾸고 싶은 점
- **크래프톤 정글 일지:** 게임랩 6기 학습과 팀 개발 기록

현재 크래프톤 정글 게임랩 6기에 참여하고 있습니다. (2026.08.31 ~ 현재)
